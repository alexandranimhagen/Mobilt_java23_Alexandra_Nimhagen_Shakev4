Flutter Shake Detector App (Shake v4)

A Flutter mobile app that detects device shake events and responds with interactive UI feedback. Developed as part of a Java YH-course to showcase real-time sensor handling and user interaction.

Features

- Detects device shake using accelerometer sensors  
- Provides visual or haptic feedback on shake  
- Tracks shake count and displays it dynamically  
- Cross-platform support (Android & iOS)

Technologies Used

- Flutter & Dart  
- Sensor handling with `sensors_plus` (or similar)  
- State management via `StatefulWidgets` and `setState()`  
- UI updates in response to sensor events

How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/alexandranimhagen/Mobilt_java23_Alexandra_Nimhagen_Shakev4.git
Open in Android Studio, VS Code, or IntelliJ with Flutter support

Run flutter pub get to install dependencies

Launch on a physical device or emulator:

flutter run
